1353UDH - VERTICAL & HORIZONTAL GRIPS

Properties

  • Sews vertical and horizontal handles on the same machine
  • Double head attaches both ends of the handle simultaneously
  • Wide stainless steel top with folded front and back edges (contoured design) for easy border loading
  • Independently adjustable guides allow vertical handles to align with temporary seam edges
  • Clamps hold the border and create a hard stop for precise handle connection
  • Varying arm lengths for flexible configurations
  • Both heads lock in place and can be repositioned at the push of a button
  • Handle programming via touch screen enables custom stitching
  • Curb guides ensure correct handle placement on the curb
  • Pedal operation frees operator’s hands during border handling
  • Magnetic mounts facilitate quick tool changes
