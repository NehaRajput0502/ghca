DY 1201S Single Head Embroidery Machine

Features:

  • Emb. Area 300mm X 350mm
  • Intelligent full color touch screen with slide mode, buttons change as screen changes
  • 9 embroidery frame visualization options
  • U disk or network mode input
  • Supported batch mode for pattern input, output, and delete
  • 600,000,000 needle storage capacity, supports up to 20,000 patterns and 250 color changes
  • Supports sequin, cording, rhinestone hot fix and other special functional devices (optional)
  • Pad and PC can directly control the machine
  • Finished garment embroidery speed up to 1200 rpm; cap embroidery 600 rpm
  • Supports 15 needles color change
  • Supports multiple languages including Chinese, English, French, Spanish, Turkish, Portuguese, Russian, Arabic, Thai, Dutch, German, Italian, Vietnamese, and 13 other languages
  • Input voltage AC80-AC260V
  • 34V working power to protect operator safety
